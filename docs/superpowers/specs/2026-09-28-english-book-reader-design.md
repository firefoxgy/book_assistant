# 英语书伴读 Android 应用设计

## 目标与范围

面向阅读英语 PDF、EPUB 的中文用户，提供按段英中对照、点词或选中短语查看释义与发音，以及可管理的生词本。应用适配 Android 手机和平板。参考图提供交互方向：阅读页底部词条弹层、独立词条详情；视觉不逐像素复制。

第一版以可选取文本的书籍为对象。扫描件 OCR、账号同步、跨设备同步、书籍批注、付费词典和 AI 生成解析不在本版范围内。

## 技术选择

原生 Kotlin、Jetpack Compose、Material 3，最低支持 Android 8.0（API 26）。单 Activity + Navigation，ViewModel 管理界面状态；Room 保存书籍、段落、翻译缓存、生词和阅读位置；DataStore 保存阅读偏好。PDF 通过 Android 兼容的文本提取库读取，EPUB 解包并按 spine 顺序解析 XHTML。导入使用系统文件选择器和持久 URI 权限；应用将源文件复制进私有目录，以避免原文件移动后失效。

英中翻译使用 Google ML Kit 设备端翻译模型。首次使用需下载模型，下载失败时显示英文和重试入口；已有缓存译文照常显示。词典以 Free Dictionary API 的英文释义、音标和例句为基础，中文释义由设备端模型翻译并缓存。词典接口无对应条目或离线时，显示单词/短语的机器翻译和原文例句（如有）；不把机器翻译冒充词典定义。英、美发音通过系统 TextToSpeech 的 en-GB、en-US locale 分别播放；设备缺少相应语音数据时给出提示。该方案无需用户提供 API 密钥，但首次翻译模型下载、首次词典查询需要网络；免费词典接口的可用性也会影响新词条详情。

## 用户流程与界面

书架显示已导入书籍、格式、阅读进度，提供导入、继续阅读、删除书籍。导入时校验 MIME 与扩展名，解析失败说明原因；空白、图片型 PDF 明确提示不含可提取文本。重名书以文件身份区分，避免误覆盖。

阅读页按书籍章节和自然段显示英文，中文译文紧跟英文段落。EPUB 以文档块级段落为边界；PDF 根据文本布局重建段落，并允许结果存在格式差异。长段按句群拆分，保证英中对应且避免一次翻译过长。翻译逐段异步生成并持久缓存，加载中有占位提示，失败可重试。阅读位置保存到段落，字体大小可调整。

单击单词打开底部词条弹层；长按并拖选连续文本后可查短语。弹层展示原文、中文释义或翻译、英美朗读按钮、例句及“加入生词本”。单词若有词典数据，展示音标和词性；短语以翻译结果为主，不承诺词典音标。添加时以标准化词形或短语去重，重复添加保留原词条并补充来源。弹层可进入完整词条页查看全部例句。

生词本可搜索并按添加时间浏览。词条详情展示中文释义、音标（有数据时）、英美朗读和例句；支持从列表或详情删除，并提供短暂撤销。已收藏词条离线可读；语音可用性取决于设备 TTS 数据。

手机使用单栏、底部导航与底部词条弹层；平板在宽窗口中采用书架/阅读或阅读/词条双栏，词条固定在侧栏。布局按窗口尺寸而非设备型号切换。触控目标、动态字体和屏幕阅读器标签符合 Android 无障碍惯例。

## 数据与边界

`Book` 保存文件位置、格式、标题、导入时间和阅读位置；`Passage` 保存顺序、章节与英文原文；`Translation` 以段落 ID 和目标语言缓存；`VocabularyEntry` 保存规范化查询、中文解释、词典数据、例句、添加时间和来源书籍/段落。解析、翻译、词典、语音、持久化各自通过接口与 ViewModel 隔离，便于替换外部服务。

文件解析和模型翻译在后台线程进行；导入取消或失败不得留下可见的半成品书籍。外部词典只接收用户主动查询的词或短语；书籍全文不上传到词典。翻译模型下载状态和联网失败均在界面明确展示。删除书籍不删除生词；删除生词只影响生词本，不修改书籍。

## 验收与验证

使用含文字的 PDF 和 EPUB 各导入一本，验证章节/段落顺序、英中对应、关闭重开后的阅读位置和译文缓存。分别验证点词、选短语、英美朗读、添加/去重/删除/撤销生词、例句展示。验证首次模型下载、断网已有缓存、词典缺词、图片型 PDF、损坏文件。用手机窄屏和 7–11 英寸平板宽屏检查阅读、弹层及双栏；运行单元测试、构建和设备或模拟器上的关键路径测试。
